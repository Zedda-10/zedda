# zedda

Sito web landing page realizzato in HTML, CSS e JavaScript.

## Struttura

- `index.html` — pagina principale
- `style.css` — design e layout
- `script.js` — script di base

## Avvio

Apri semplicemente `index.html` nel browser oppure pubblica il progetto su GitHub Pages.

## Personalizzazione

Puoi modificare testi, colori e contenuti direttamente nei file HTML/CSS.
